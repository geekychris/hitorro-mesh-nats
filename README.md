# Hitorro Mesh Nats

NATS-backed MeshTransport implementation for Hitorro Mesh — the production transport for task dispatch, result streaming, and heartbeats. Supports TLS, credentials/token/nkey auth, and drops in as a replacement for the in-JVM test transport with no driver or agent changes.
